% Aim of this report  
This report aims to study the solutions of Reaction Diffusion Systems and explore their far reaching applications outside of mathematics and chemistry. This study will be used in developing a python program that is capable of producing Turing Patterns.

% Structure of report  
The report has been organized to start with a generalist introduction to Reaction Diffusion Systems followed by a mathematical overview of the topic. In particular, we will investigating the solutions of this class of partial differential equations using stability and bifurcation analysis. Studying the solutions of this project is perhaps the most interesting part of this project as they are partly the reason for choosing this topic. The second part of this report will explore the applications of Reaction Diffusion Systems in a variety of domains such as biology, ecology, physics, etc. The final part of this report will demonstrate original contribution from everything that has been learned in the research and conclude with a summary of the topic and the original contribution.
